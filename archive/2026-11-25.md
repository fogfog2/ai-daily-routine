30개 고정 seed 분할·train 전용 변환·가설군별 통계 보정으로 일반적인 routing 개선이 단일 최선 모델을 일관되게 이기지는 않는다고 보고했다. 긍정 결과는 주로 특정 Omni-MATH 모델 조합·평가 절차에 한정되며 IFEval은 예측기 선택에 민감했다. 여러 seed를 독립 증거처럼 취급하는 분석과 더 보수적인 보정의 차이도 공개했다.
비용 분석은 parameter 수 대용 지표이며 실제 API 요금·통제된 지연 측정이 없다. 연구 범위는 single-turn 평가로 multi-turn·도구 사용·agent 배포 비용은 제외한다. 따라서 최신 Claude·Codex의 모델/effort별 추천 순위나 저렴한 모델로 자동 라우팅하면 돈·시간이 절약된다는 실증값으로 사용할 수 없다.

그래서: Astra·Sol·Luna와 Claude를 작업별로 선택하는 시스템에서도 평균 benchmark 순위만으로 router의 이득을 가정하면 안 된다. 실제 대상 조합의 동점·선택 여지·검증셋 성능·실제 비용을 먼저 확인하는 평가 관점이다.

## REE 연구 평가 — Opus 5.5·Sol 6.1의 최고 추론 설정과 과학 과제 개선 비교

- 분류: `연구`
- 출처: https://arxiv.org/abs/2611.34646v1

REE: A Scientific Research Entrance Exam for AI Agents v1은 11-25 16:25:19 UTC에 제출됐다. 5개 과학 영역·23개 domain의 100개 과제에서 작동하는 starter 해법을 반복 개선하고, agent가 보지 못하는 held-out 자료로 기존 expert 해법과 같은 평가를 수행한다. 본문: https://arxiv.org/html/2611.34646v1
점수 0은 starter, 100은 과제 metric의 상한으로 정규화한다. 평균은 Claude Opus 5.5·Claude Code 39.6, GPT-6.1 Sol·Codex 38.2, expert 해법 24.4였다. 기존 expert 해법보다 높은 과제 비율 86%·81%는 전체 과학 문제를 해결한 비율이나 인간 연구자 전체를 이긴 확률이 아니다. 같은 분야의 기존 방법을 조정·결합한 사례가 대부분이라고 분석했다.
각 agent는 해당 모델의 최고 reasoning effort·최대 context에서 자연 종료 또는 12시간까지 실행하고 모델·과제당 run은 1회다. 본문은 최고 수준으로 명시하지만 동일한 low/mid/high/xhigh/max sweep을 제공하지 않는다. 공식 저장소의 예시에는 이전 모델 이름·effort flag도 있어 그 값을 본문 대상 모델의 정확한 설정명으로 대신 쓰지 않는다. 저장소: https://github.com/aiming-lab/RSI-Exam
95% bootstrap 구간은 task 재표집으로 Opus 36.0–43.2, Sol 34.2–42.3이며 같은 task의 반복 실행 변동을 추정한 것이 아니다. 연구 범위는 코드로 제한 시간 안에 채점 가능한 개선 과제이고 물리 실험·새 데이터 수집·인간 판단 연구는 제외한다. 최신 Astra/Sol 6.2·Luna·Fable·Sonnet 순위나 모든 effort·실제 비용·지연 우열은 측정하지 않았다.

그래서: 과학 agent의 성능을 기존 해법 대비 개선량·실행 과정으로 비교하는 공개 평가다. Opus와 Sol의 해당 설정 결과를 참고하되 숨은 평가의 점수와 보편적 연구 능력·실험적 발견을 분리해서 읽어야 한다.
