## Gemini 4 Carbon 발표 — 사이버 방어 중심 제한 접근, 일반 공개는 추후

- 분류: `모델`
- 출처: https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/

Google은 10월 28일 장기 에이전트 작업·소프트웨어 개발·사이버 방어를 겨냥한 Gemini 4 Carbon을 발표했다. 발표 당시 일부 사이버 방어 조직부터 주중 제공하고 Fairwind의 신뢰된 파트너로 확대할 계획이며, 일반 개발자·기업·소비자 대상 제품 제공은 추후라고 설명했다.
SEC-bench Pro 88.2%·ExploitGym 54.8%·CWE-bench 71.0%를 제시했다. 이는 Google이 공개한 평가 결과이며 해당 사이버 벤치마크는 guardrail 없이 평가했다고 명시한다. 외부 벤치마크를 썼다는 사실을 독립 제3자 재측정이나 실제 서비스의 동일 조건 성능 보장과 혼동하지 않는다.
출시 시 도입 가격으로 100만 토큰당 입력 $2·출력 $10과 캐시 입력 95% 할인을 예고했다. 각주상 도입 기간이 끝나면 입력 $4·출력 $20이 적용된다. 일반 고객이 지금 이 단가로 API를 호출할 수 있다는 발표가 아니며 도입 가격을 영구 요율로 쓰지 않는다.
Carbon의 공급사 평가를 기존 Claude·Codex의 독립 벤치마크 스냅샷에 합산하지 않았다. 모델·하네스·effort·보호 장치가 다른 결과를 같은 설정의 우열로 해석하지 않는다.

그래서: 장기 코딩·보안 에이전트의 비교 후보가 늘었지만 현재 접근 자격과 출시 후 요율을 확인해야 한다. 일반 이용 가능 시점과 독립 평가가 확보되면 같은 조건으로 비교할 수 있다.

## OpenAI, 적격 Pro·Business에 API 크레딧 혜택 — Codex 사용량과 별도

- 분류: `도구`
- 출처: https://help.openai.com/en/articles/20001626-api-credits-benefit-for-eligible-chatgpt-subscriptions

OpenAI는 10월 28일 API 변경 기록과 ChatGPT 릴리스 노트에서 적격 유료 Pro·Business의 API 크레딧 혜택을 발표했다. 본인이 소유한 API 조직 하나에 연결해 활성화하며, 로그인한 Codex·ChatGPT 사용 한도가 늘어나는 혜택과 다르다. API 키를 통한 Codex 사용에도 적용되지 않는다고 안내한다.
월 결제 기간 전체 기준 Pro 100·200·500 티어는 각각 $100·$200·$500다. Business는 유료 Standard 좌석당 $20·Premium당 $100을 합산하되 워크스페이스 월 최대 $500이며, 연간 선결제는 연 최대 $6,000 조건이다. 첫 지급은 남은 결제 기간에 따라 비례 계산한다.
적격 유료 구독이 최소 7일 활성 상태여야 하고 동일 이메일·양쪽 소유 권한·조직 연결 조건을 충족해야 한다. Plus·무료 체험은 대상이 아니며 Enterprise·Edu·기존 Codex 좌석도 적격으로 안내되지 않는다. 국가·제공 집단에 따른 노출 차이가 있어 실제 혜택과 지급을 확인해야 한다.
미사용 크레딧은 결제 주기 말 만료돼 이월되지 않으며 API 요율·요청/토큰 한도는 유지된다. API 과금과 구독 과금도 별도다.

그래서: API로 에이전트나 도구를 만드는 이용자는 실험 예산을 줄일 수 있지만, Codex 구독 작업이나 API 키 Codex 실행 비용까지 무료라고 가정하면 안 된다. 실제 지급액·대상 조직·만료와 API 사용 범위를 확인해야 한다.

## Microsoft Copilot 하네스, Foundry Agent Service 공개 미리보기

- 분류: `도구`
- 출처: https://devblogs.microsoft.com/foundry/microsoft-copilot-harness-in-foundry/

Microsoft는 10월 28일 Foundry Agent Service의 Copilot 하네스 공개 미리보기를 발표했다. Microsoft·GitHub의 여러 Copilot 제품에 쓰는 실행 기반을 관리형 서비스로 제공하는 변화이며 새 모델 발표는 아니다. 함께 발표한 hosted agents의 장기 실행 복원력 정식 제공과 하네스 미리보기를 구분한다.
Microsoft가 에이전트 루프·샌드박스를 운영하고 개발자는 지식·절차·스킬·도구와 지원 모델을 선택한다. 재사용 스킬, 인증·승인을 명시한 MCP 도구, 파일·코드 실행과 제한된 하위 작업 위임, 소스 관리 가능한 에이전트 정의를 묶는다. 공급사의 성능·효율 주장을 독립 모델 벤치마크와 합산하지 않는다.
미리보기에서는 에이전트 생성 시 하네스를 선택하며 생성 후 하네스 전환은 아직 지원하지 않는다. 기존 에이전트는 바뀌지 않고 실행 환경의 CPU·메모리·유휴 설정은 Foundry가 관리한다. 지역·모델·도구 지원 한도도 별도로 확인해야 한다.
하네스 실행 사용료는 2026년 12월 1일부터 소비량 기준으로 부과할 예정이다. 그 전에도 모델 추론·별도 과금 도구·연결 서비스는 과금 대상이다. 공지 기준 샌드박스는 vCPU 시간당 $0.0994·GiB 시간당 $0.0118이며 지역·계약에 따라 달라질 수 있다.

그래서: 여러 모델을 같은 실행 기반에서 평가·운영하는 관리형 선택지가 늘었다. Claude·Codex 도구와 비교할 때 모델·effort 외에 하네스·도구 권한·샌드박스 비용과 복구 조건을 함께 비교해야 한다.
