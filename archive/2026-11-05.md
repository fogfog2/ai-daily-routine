- 분류: `도구`
- 출처: https://platform.claude.com/docs/en/release-notes/overview#november-5-2026

Anthropic은 11월 5일 Claude Console 조직의 IP 허용 목록을 베타로 발표했다. 조직당 IPv4·IPv6 주소 또는 CIDR 범위를 최대 1,000개 등록하고, 대상 서비스에 목록 밖 주소로 접속한 요청을 거부한다.
가이드는 Messages·Files 등 Claude API와 Managed Agents의 관리 엔드포인트 등을 대상으로 명시한다. Managed Agents 런타임 내부의 네트워크 통제에는 적용되지 않으며 Bedrock·Claude Platform on AWS·Google Cloud·Foundry 경로도 이 목록의 적용 대상이 아니다.
같은 날 Claude Enterprise 조직은 Admin API의 `POST /v1/organizations/users/{user_id}/sign_out`을 베타로 사용할 수 있게 됐다. `write:members` 권한과 `admin-user-sign-out-2026-10-08` 베타 헤더가 필요하다. 헤더의 날짜는 이번 기능 발표일과 다르다.
이 요청은 계정 전체의 로그인 세션·신뢰 기기와 해당 조직의 OAuth 토큰을 종료한다. API 키·다른 조직의 OAuth 토큰·Claude Code 클라우드 세션·예약 루틴은 종료하지 않으며, 구성원 자격은 유지돼 즉시 다시 로그인할 수 있다.

그래서: API·무인 에이전트의 접속 네트워크와 사용자 세션을 따로 관리할 수 있다. 전체 로그아웃을 키 폐기나 실행 중인 클라우드 작업의 중단으로 취급하지 않아야 한다.

## GPT-6 Cyber 발표 — 승인된 일부 Daybreak Red 고객에게 API·Codex로 제한 제공

- 분류: `모델`
- 출처: https://openai.com/index/introducing-gpt-6-cyber/

OpenAI는 11월 5일 보안 연구 모델 GPT-6 Cyber를 발표했다. 처음에는 승인된 일부 Daybreak Red 고객만 API·Codex에서 사용할 수 있으며, 모든 Red 고객으로 확대하는 것은 향후 계획이다.
공급사 평가의 ExploitGym 성공률은 GPT-6 Cyber 48.5%, GPT-5.6 Cyber 32.1%다. 약 51% 상대 향상이라는 설명은 이 평가의 결과이며 Claude·Astra·Sol의 일반 코딩 작업이나 같은 effort의 독립 비교로 확대할 수 없다.
별도 범위 준수 실험에서 배포용 프롬프트 없이 99.93%, 프롬프트를 사용하면 100%의 시행에서 범위 밖 서비스를 공격하지 않았다고 밝혔다. 이는 공급사의 제한된 실험 결과이며 모든 실제 배포에서의 준수 보장은 아니다.
Daybreak Red API는 기본적으로 IP 허용 목록을 요구하며 일부 예외가 있다. ZDR API 고객도 일반적으로 고객 저장소의 암호화 기록을 30일 보관·검사하는 Private Safety Processing을 사용해야 한다고 설명했다.

그래서: 승인된 보안 연구에는 새 선택지가 생겼다. 일반 Codex 구독의 새 기본 모델로 간주하지 말고 접근 승인·실행 범위·데이터 처리 조건을 확인해 도입하면 된다.

## Gemini Omni 1.2 Flash 정식 제공 — 최대 15초 영상과 낮아진 출력 요금, 1.1 전환 예고

- 분류: `비전`
- 출처: https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/

Google은 11월 5일 Gemini Omni 1.2 Flash를 Gemini API 유료 티어 등에 정식 제공한다고 발표했다. Gemini 앱의 Google AI Ultra 대상 배포는 순차적으로 진행한다고 설명했다.
일반 영상 생성·대화형 편집은 최대 15초를 지원한다. API 변경 이력은 첫·끝 프레임 보간을 3~10초, 영상 연장을 턴당 3~10초·전체 최대 30초로 구분하므로 모든 방식이 한 번에 15초인 것은 아니다.
Standard 동영상 출력 가격은 100만 토큰당 12달러로 전작보다 약 30% 낮아졌다. 공식 가격표의 720p 초당 5,792토큰 기준으로 약 0.07달러/초이며 입력은 별도다. 변경 이력은 유료 티어 처리 한도도 2배로 늘었다고 밝혔다.
12월 3일부터 `gemini-omni-1.1-flash` API 요청을 1.2로 자동 연결하고 1.2 요율을 적용할 예정이다. 이는 향후 전환 공지이며 확인일 현재 이미 모든 1.1 요청이 전환됐다는 뜻은 아니다.

그래서: 영상 자동화에서 길이·편집 기능과 출력 비용을 함께 조정할 수 있다. 보간·연장별 길이 제한과 12월의 모델 자동 전환을 작업 흐름에 반영하면 된다.

## Gemini API, Office 파일 입력·멀티모달 도구 응답 확대 — ODS는 첫 시트만 처리

- 분류: `도구`
- 출처: https://aistudio.google.com/docs/changelog#11-05-2026

Google은 11월 5일 Gemini API의 PPT·ODP·ODS 입력 지원과 DOC 페이지 이미지 처리를 추가했다. DOCX·DOTX·ODT·PPTX·XLSX·XLS의 기존 처리 방식은 바뀌지 않았다고 명시했다.
DOC·PPT·ODP는 전체 페이지·슬라이드를 이미지로 처리한다. ODS는 첫 시트의 데이터와 수식만 전달하며 다른 시트는 무시한다. 기존 XLSX·XLS도 첫 시트만 읽되 값만 전달하므로 형식별 차이가 있다.
GenerateContent의 함수 응답에는 Office·OpenDocument 파일과 음성·영상을 담을 수 있고, `fileData`로 Files API URI를 돌려줄 수도 있다. `inlineData`·`fileData`의 `displayName`과 영상 처리 모드도 지원한다.
Interactions의 `function_result`에는 `document`·`audio`·`video` 블록을 인라인 데이터나 URI로 전달할 수 있다. 영상 블록은 `v1beta`·`v1alpha`에서 제공되며 파일은 일반 입력과 같은 방식으로 처리된다.

그래서: 도구가 생성한 문서·음성·영상 파일을 에이전트의 다음 판단에 바로 돌려줄 수 있다. 여러 시트가 있는 자료는 필요한 시트를 첫 위치로 옮기거나 파일을 나누어 처리해야 한다.

## Inkling 2 Small 제공 시작 — 이미지 입력·가변 effort, 가중치 공개는 안전 평가 후 계획

- 분류: `모델`
- 출처: https://thinkingmachines.ai/news/inkling-2-small/

Thinking Machines Lab은 11월 5일 총 5,940억·활성 170억 파라미터의 MoE 모델 Inkling 2 Small을 소개했다. 텍스트·이미지를 받아 텍스트를 출력하며 모델 카드는 최대 100만 토큰 문맥과 가변 effort를 안내한다.
초기에는 Tinker에서 비공개 가중치로 추론·미세조정을 제공한다. 외부 안전 평가·red teaming 완료 뒤 다음 주 Apache 2.0으로 전체 가중치를 공개할 계획이라고 밝혔다. 모델 카드의 제공 약관은 Tinker Terms of Use이며 계획을 실제 가중치 공개 완료로 쓰지 않았다.
공급사 자체 평가 설정은 effort 0.99(`xhigh`)·temperature 1.0·최대 100만 토큰 trajectory다. 블로그는 외부 평가 점수와 자체 평가를 함께 제시하므로 전체 표를 독립 기관의 동일 조건 Claude·Codex 순위로 취급할 수 없다.
공급사는 음성 입력을 지원하지 않으며, 스킬이 많은 코드베이스에서 항상 최적의 도구를 고르지는 않고 대화의 간결함·구성에도 한계가 있다고 밝혔다. 모델의 최대 문맥과 서비스의 실제 사용 한도도 구분해야 한다.

그래서: 시각 피드백이 필요한 장기 코딩·자동 연구의 새 후보로 검토할 수 있다. 직접 호스팅은 실제 가중치 공개와 라이선스를 확인한 뒤 판단하고, 현재 Tinker 제공 범위에서 자신의 작업을 평가하면 된다.
