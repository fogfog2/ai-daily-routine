권한·추가 디렉터리 저장 실패를 경고하고, 신뢰된 상위 폴더 아래의 신뢰 질문에서 Up·Enter가 Yes로 답하던 문제와 setup의 추가 Enter가 auto mode 기본 사용을 수락하던 문제를 수정했다. 삭제·덮어쓰기 명령을 검색·읽기로 요약하던 transcript 표시도 바로잡았다.

## Google Deferred tier GA — 비실시간 에이전트 추론 50% 할인과 대기 조건

- 분류: `도구`
- 출처: https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/deferred-tier

Google은 Agent Platform 공식 변경 이력 11-16에서 Deferred tier의 GA와 ADK 2.10.0 이상 에이전트 지원 확대를 발표했다. custom·제3자 에이전트의 비동기 Interactions API 호출도 지원하며 즉시 응답이 필요 없는 작업을 off-peak 실행으로 보낸다. 발표일 근거: https://docs.cloud.google.com/gemini-enterprise-agent-platform/release-notes
같은 모델의 Standard PayGo 대비 입력·출력·thinking token 요금이 50% 낮다. 계약·암묵적 캐시 할인과 중첩할 수 있고 Standard 요금으로 자동 fallback하지 않는다. 이는 모델 추론 요금으로 cloud 호스팅·외부 도구 등 전체 agent 비용이 무조건 절반이라는 뜻은 아니다.
요청은 global Interactions endpoint에서 background=true·store=true로 제출한다. 완료는 24시간 목표이고 state는 7일 보존하며 다중 turn은 각각 대기·과금된다. regional 및 us/eu multi-region endpoint는 지원하지 않는다. 실제 대기는 용량·수요에 달려 즉시 실행이나 24시간 이내 완료 보장이 아니다.
ADK는 use_interactions_api=True 모델과 RunConfig의 ServiceTier.DEFERRED로 사용하고 token streaming과 함께 쓸 수 없다. 클라이언트·프록시 timeout으로 polling이 끝나도 backend 작업과 과금은 계속될 수 있다. 큐에서 취소한 turn과 이미 실행을 시작한 model call의 청구 조건도 다르다. ADK 안내: https://docs.cloud.google.com/gemini-enterprise-agent-platform/scale/efficiency/autonomous-scheduling

그래서: 예약 조사·코드 이행·보안 scan·대량 agent 평가처럼 지연을 감수할 작업의 추론 비용을 줄일 선택지다. effort를 낮추는 방식과 구분하고, queue 대기·turn 수·종료 처리·전체 운영비를 함께 비교해야 한다.
