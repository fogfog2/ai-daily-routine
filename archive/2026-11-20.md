OpenAI는 11-20 MedChemBench 설명 글에서 GPT-6.2 Astra 결과를 추가로 공개했다. 연결된 논문 PDF 표지는 11-09이고 GPT-6.2는 PDF에 없으므로 이번 글을 논문 최초 발표나 새 약물 발견으로 바꾸지 않는다. 논문: https://cdn.openai.com/pdf/09c4ec60-a32e-4652-837b-1811368a3bb0/medchembench-paper.pdf
평가는 논문·특허 117건의 분자 구조 761개를 바탕으로 한 99개 문제다. 공통 xhigh에서 GPT-6.2 Astra 84.5%, GPT-6 Astra 83.3%, GPT-6.1 Sol 82.0%의 available credit을 보고했다. 부분 점수를 포함하므로 전체 문제 성공률이나 실제 후보 약물 성공률이 아니다.
GPT-6 Astra의 분자 구조 항목은 xhigh에서 95.4%지만 후보 선택·수치 예측은 약 절반의 점수였다. 같은 모델의 max 총점 83.8%는 xhigh와 다른 설정이다. 점수·분야별 채점 기준·thinking을 포함한 출력 토큰을 구분해야 하며 작은 점수 차이만으로 통계적 우위를 확정하지 않는다.
각 답변은 도구·피드백·새 실험 없는 단일 시도이며 발표된 출처의 학습 중 사전 노출을 배제하지 못한다고 밝혔다. 공급사 평가이고 Claude 모델과의 직접 비교도 없으며 새로운 약물 발견이나 실제 실험 의사결정 개선을 입증한 결과는 아니다.

그래서: Astra·Sol의 동일 xhigh 화학 추론 결과를 비교할 추가 자료다. 구조 복원 능력과 후보 선택·예측·실험 검증을 분리해 읽어야 하며 전체 agent 업무 성능 순위로 확대하지 않아야 한다.

## Luna low 추론과 빠른 결정 모델의 비교 — 48개 합성 과제의 지연·견고성 trade-off

- 분류: `연구`
- 출처: https://arxiv.org/abs/2611.27679v1

연구진은 11-20 14:50:54 UTC 제출한 Too Fast to Doubt? 논문에서 4개 빠른 결정 모델을 1,440개 paired 합성 브라우저 과제로 평가했다. 외부 댓글의 잘못된 결론·근거 해석에 대한 취약성을 보았으며 실제 전체 웹 agent 성공률 시험은 아니다. 본문: https://arxiv.org/html/2611.27679v1
깨끗한 입력의 평균 정확도는 91.0%였지만 두 번의 공격 기회를 준 조건에서 공격 성공은 81.2%에 달했다. 높은 clean 정확도·확률 calibration을 prompt injection 저항성으로 해석할 수 없다는 저자 평가다.
48개 matched 과제의 Cautious prompt 조건에서 GPT-6 Luna low는 오염 입력 정확도 95.83%, native Luna Decisions는 38.54%였다. 평균 보고 reasoning은 30토큰 미만이었고 선택된 generation의 평균 지연은 0.29초에서 1.94초로 늘었다. 다른 prompt 조건에서는 수치가 달라 95.83%를 무조건적인 방어율로 쓰지 않는다.
지연은 선택된 generation의 OpenRouter Total Latency로, 브라우저 실행·전체 작업 완료 시간과 다르다. 작은 합성 subset과 인터페이스·prompt 조건의 비교이며 모든 low/medium/high·Claude·Astra·Sol 평가나 일반적 인과 효과를 입증한 것은 아니다.

그래서: 짧은 추론도 낮은 지연의 결정 인터페이스와 다른 견고성·속도 균형을 보일 수 있다. 라우팅 모델을 고를 때 clean 정확도·공격 조건·지연을 함께 측정하고 실제 업무 데이터로 재검증해야 한다.
