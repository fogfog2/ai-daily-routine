## REA 6.8.0 — 캡처 기반 에이전트 환경과 분석 결과 형식 변경

- 분류: `도구`
- 출처: https://github.com/morluto/rea/releases/tag/rea-agents-6.8.0

REA는 10월 25일 08:36 UTC에 6.8.0 정식 릴리스를 공개했다. 네트워크 캡처·브라우저 시나리오·프롬프트에서 로컬 에이전트 환경을 만들고, 파생된 읽기와 증거에 근거해 허용한 쓰기를 제공하는 기능을 소개했다.
GPU 코드 객체·Python 바이트코드·Unity IL2CPP·Godot PCK 등 분석 형식을 확대하고, 큰 조사에서 요약·선택 조회·행 단위 CLI 출력을 지원한다고 밝혔다. 릴리스 기능 설명이며 독립 성능 평가나 모든 앱의 완전 재현을 입증한 결과는 아니다.
analyze_function의 기본 반환이 보존된 요약으로 바뀌었다. 기존 전체 분석이 필요한 호출은 detail: "complete"를 지정해야 하며, CLI 기본은 전체 출력으로 유지된다. JSONL 소비자는 마지막 메타데이터 레코드를 일반 객체 행과 구분해야 한다.
입력 스키마 안내는 기본적으로 compact이며 REA_MCP_INPUT_SCHEMA_PROFILE=full로 전체 안내를 선택한다. 기존 Evidence·재구성 증명·바인딩 처리에도 호환성 변경이 있어 공식 breaking changes를 확인해야 한다.

그래서: 역공학 결과를 에이전트 실험 환경으로 이어갈 수 있지만, 기존 MCP·CLI 연동은 응답과 JSONL 파서를 먼저 점검해야 한다.
