그래서: 에이전트를 한 번 실행하는 것에서 상태·사건 기반 조사 공정으로 확장한 사례다. 실제 운영에는 독립 검토·사람의 변경 승인·배포 후 측정과 모델/skill 변경 평가가 필요하다는 근거를 제공한다.

## Replit 다중 에이전트 평가 — Astra의 단독 성능과 Opus 팀 확장성은 달랐다

- 분류: `연구`
- 출처: https://frontier.replit.com/throwing-headcount-at-the-problem/

Replit은 11-19 Optimization-Bench의 NumPy·SQLite·SQLGlot·Git 성능 최적화 평가를 공개했다. Replit Agent 하네스에서 Opus 5.5·Sonnet 5.5·GPT-6.2 Astra·GPT-6 Astra·GPT-6.1 Sol을 medium, GPT-6 Luna를 high로 실행했다. Claude Code·Codex 제품이나 모든 effort의 공통 평가가 아니다.
단독·8·16·32개 에이전트 구성을 비교하고 각 에이전트에 8 vCPU·16 GiB·2시간을 주었다. 같은 벽시계 시간이지 같은 총 계산량·달러 예산은 아니다. 최종 branch를 별도 VM으로 옮겨 public·hidden·생성 테스트로 출력·동작을 검사하고 전용 Intel 머신에서 실행 성능을 측정했다.
NumPy 13개 workload에서 Opus 단독이 만든 코드는 기존 대비 3.7배, 32개 팀은 18.9배의 중앙값 속도 향상을 보였다. 이는 최적화된 프로그램의 실행 속도로 에이전트 응답 속도나 전체 개발 시간 단축률이 아니다. GPT-6.2 Astra는 가장 강한 단독 결과였지만 32개 팀은 네 과제 중 세 과제에서 단독 결과보다 낮았다.
보고서는 작업 소유권·공유 게시판 중심 협업이 유리했던 반면 coordinator의 직접 메시지 부담과 같은 파일을 둘러싼 충돌이 확장을 막았다고 분석한다. 분리 가능한 workload와 좁은 공통 코드의 결과가 달랐으며 공급사 하네스의 제한된 평가라 일반 모델 순위·팀 비용 효율로 확대하지 않는다.

그래서: 단독 복잡 작업에 좋은 모델이 큰 팀에서도 최선이라고 가정하면 안 된다. 이 medium 중심 조건에서는 Astra의 단독 능력과 Opus의 팀 협업이 달랐고, 선택은 작업 분해·통신·계산 예산까지 함께 비교해야 한다.

## Asta에 Theorizer 공개 — 문헌 근거로 가설을 만들고 Python 라이브러리로 연결

- 분류: `과학`
- 출처: https://allenai.org/blog/theorizer-in-asta

Ai2는 11-19 Theorizer를 Asta에 제공하고 코드로 연구 흐름을 확장하는 방법을 공개했다. 공식 저장소는 웹 Generate Theories, 새 Python library 0.2.0, 기존 독립 서버의 세 경로를 설명한다. 원 연구는 ACL 2026이므로 이 날을 논문·이론 생성 기술의 최초 발표일로 바꾸지 않는다. 저장소: https://github.com/allenai/asta-theorizer
질문에 맞는 문헌을 찾고 논문별 추출 template을 만든 뒤 근거를 종합해 설명을 제안한다. 각 주장은 출처와 적용 조건을 연결하지만, 새로운 주장이라는 표시는 검색 누락·모델 판단 오류가 있어 연구자가 더 넓은 문헌으로 확인해야 한다.
Asta 웹은 한도 내 token 비용을 제공하며 로컬 library 실행은 사용자가 토큰 비용을 부담한다. 저장소 코드 라이선스는 Apache-2.0이고 README는 Claude Code 같은 코딩 에이전트에서 library를 사용할 수 있다고 설명한다. 코드 공개와 모든 기반 모델 가중치 공개·무제한 무료 사용은 구분한다.
Ai2의 사례는 암·뇌 세포·기후·감자 다양성의 연구 가설 탐색이다. 잘못된 가설을 검증하다 데이터 문제를 찾은 사례도 소개하며 암 관련 결과 역시 추가 실험 검증이 필요하다고 명시한다. 공급사의 연구 사례이며 자동으로 참인 이론이나 임상 효과를 입증한 발표가 아니다.

그래서: 문헌 검색 요약에서 근거가 연결된 검증 가능한 가설 제안으로 확장한 도구다. 연구자가 가설·인용·조건을 검토하고 실험이나 데이터 분석으로 확인하는 흐름에 연결할 수 있다.
