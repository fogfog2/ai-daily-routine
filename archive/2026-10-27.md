- 출처: https://github.com/openai/codex/releases/tag/rust-v0.165.0

Google Cloud Vertex AI 내장 provider를 추가해 model_provider = "gcp" 설정을 지원하고 GPT-6.1 Terra를 모델 목록에 반영했다. 이는 CLI 연결·모델 선택 지원이며, 모든 Google Cloud 계정에서 OpenAI 모델이 정식 제공된다는 뜻은 아니다.
새 메모리 프로필에는 memory v2를 기본 적용하고 다른 에이전트의 메모리 가져오기를 지원한다. 저장소별 세션 필터와 디렉터리별 에이전트 보기, 실험적인 app-server 연결 스레드 분기도 추가했다. 기존 메모리가 전부 자동 이전됐다고 해석하지 않는다.
중단·계획 모드 전환 뒤 대기 중인 메시지가 작업을 다시 시작하던 문제와 marketplace URL의 검증 대상·실제 Git 접속 호스트가 달라질 수 있는 틈을 수정했다. MCP 요청 취소와 모델 미발견 오류의 불필요한 재시도도 개선했다.

그래서: 모델·effort 선택뿐 아니라 메모리와 세션·클라우드 연결을 운영하는 흐름이 바뀐다. 기존 0.164.0과의 비교는 같은 모델·effort를 고정한 뒤 도구 동작과 비용을 따로 확인해야 한다.

## Claude Code 2.1.312 — 실제 effort 표시·클라우드 루틴 설정·조직 정책 수정

- 분류: `도구`
- 출처: https://github.com/anthropics/claude-code/releases/tag/v2.1.312

Anthropic은 10월 27일 20:24:20 UTC, 한국시간 10월 28일 05:24에 Claude Code 2.1.312 안정판을 공개했다. 작업 도중 선택한 effort가 아직 모델에 적용되기 전에 표시되던 문제를 고쳐, 상태 표시·OpenTelemetry·기록이 실제 적용 수준을 나타내도록 했다.
클라우드 루틴 생성·편집의 모델 선택기에 effort 설정을 추가했다. 작업 중 /model·/effort 변경은 다음 사용자 메시지보다 먼저 캐시 재읽기를 유발할 수 있어 경고 문구를 수정했다. 모델 품질 향상이나 모든 effort 변경의 즉시 적용을 보장하는 발표는 아니다.
Bedrock·Vertex·Foundry·Mantle에서 인식하지 못하는 사용자 지정 배포 이름은 짧은 시스템 프롬프트를 사용하도록 바꿨다. CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0으로 전체 프롬프트를 유지할 수 있으므로 같은 모델 이름을 가리켜도 프롬프트 조건이 달라질 수 있다.
VS Code 확장에서 로그인한 뒤 조직 정책을 다시 가져오지 못하던 문제와, 큰 CLAUDE.md·규칙·포함 파일의 앞부분만 보고 전체를 덮어쓰던 문제를 수정했다. 하위 폴더로 이동한 뒤 경로별 스킬을 찾지 못하던 문제도 고쳤다.

그래서: effort별 속도·비용을 측정할 때 선택값과 실제 적용값, 캐시 재읽기 시점, 사용자 지정 배포의 프롬프트를 함께 기록해야 한다. 클라우드 루틴도 원하는 effort를 명시해 확인할 수 있다.

## Gemini API CLI 베타 — Claude·Codex에서 Gemini를 셸 도구로 호출

- 분류: `도구`
- 출처: https://ai.google.dev/gemini-api/docs/cli

Google은 공식 Gemini API 변경 기록의 10월 27일자 항목에서 Gemini API CLI(gemini-api) 베타를 공개했다. 셸을 사용할 수 있는 Claude Code·Codex·Antigravity 등의 에이전트, 스크립트와 CI에서 호출하는 무상태 API 클라이언트다.
Interactions API를 통해 텍스트·미디어 생성, 파일 분석과 Gemini managed agents 실행을 명령으로 요청한다. 기존 대화형 코딩 에이전트 @google/gemini-cli와 구분되며, Gemini를 직접 셸 도구로 연결하려는 용도다. API 키 인증이 필요하다.
미디어는 파일로 저장하고 경로를 출력하며, JSON 출력·구조화된 오류·종료 코드·오프라인 스키마 조회와 dry-run을 지원한다. 숨은 로컬 대화 상태 대신 interaction ID 등을 명시해 여러 단계를 연결한다.
공식 가이드는 오픈소스 베타이며 minor 버전 사이에도 호환성이 바뀔 수 있다고 설명한다. 자동화 환경과 CI에는 특정 릴리스 버전을 고정하도록 권장한다.

그래서: Claude·Codex 작업 중 Gemini의 파일·미디어·조사 기능을 명시적인 명령으로 호출하는 선택지가 생겼다. 모델별 요금과 출력 경로·실패 처리를 통제하면서 도입을 검토할 수 있다.

## Genie 4 연구 미리보기 — 소리·언어 조작을 결합한 실시간 월드 모델

- 분류: `비전`
- 출처: https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation/

Google DeepMind는 10월 27일 Genie 4를 발표했다. 장면과 함께 음악·환경음·대화를 생성하고, 카메라 이동·날씨 변경·인물이나 물체 추가를 자연어로 지시하는 실시간 상호작용 월드 모델이다.
Gemini Omni의 시각·행동 이해와 Gemini 계열의 추론을 결합해 장면의 일관성과 진행을 돕는다고 설명한다. 사실적인 물리·사람 움직임과 로봇·에이전트 훈련 환경 활용은 공급사 기능 설명이며, 독립 평가에서 로봇 성능 향상이 입증됐다는 발표는 아니다.
현재 제공은 신뢰된 테스터 대상 연구 미리보기다. Project Genie의 Google AI Ultra 구독자와 Gemini API·AI Studio 조기 접근 파트너 확대는 추후 계획이며 대기 신청을 받는다. 모든 Ultra 가입자나 일반 API 고객에게 즉시 정식 제공된다고 소개하지 않는다.
긴 세션·복잡한 편집·장면 이동에서 물체 지속성과 세부 정보가 흔들릴 수 있고, 복잡한 물리·실시간 음성 정확도·읽을 수 있는 글자·공간 정확도도 연구 과제라고 명시했다.

그래서: 정해진 영상을 생성하는 데서 사용자 입력에 반응하는 환경을 만드는 방향의 변화다. 에이전트 실험 환경으로 쓸 때는 접근 자격과 장기 일관성·물리 정확도를 먼저 검증해야 한다.
