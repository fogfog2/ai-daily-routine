## Codex CLI 0.166.0 — 세션 복원·reasoning 토큰 집계·네트워크 진단 개선

- 분류: `도구`
- 출처: https://github.com/openai/codex/releases/tag/rust-v0.166.0

OpenAI는 10월 29일 19:47:53 UTC, 한국시간 10월 30일 04:47에 Codex CLI 0.166.0 안정판을 공개했다. 재개·분기 시 승인된 권한 설정과 reasoning 토큰 집계를 보존해 불필요하게 이른 대화 압축을 피하도록 수정했다.
codex queue --resume은 메시지를 대기열에 넣은 뒤 메모리에서 내려간 스레드를 재개하고, codex doctor --network-only는 설정·접속·WebSocket 문제를 집중 진단한다. 부모를 보관 해제할 때 하위 스레드 복원과 재접속 복구도 개선했다.
단어·행·페이지 단위 키보드 기록 선택과 통합 검색, 비동기 질문·답변의 Markdown 표시를 추가했다. Terra를 기본·Vertex AI·Bedrock 모델 목록에도 반영했으며, 모델 서비스의 계정별 접근 권한까지 새로 보장한 것은 아니다.
이번 변경은 CLI 동작·계측·운영 안정성에 관한 발표다. 새로운 reasoning effort 단계나 모델 자체의 벤치마크 점수·토큰 단가 인하를 발표한 것으로 해석하지 않는다.

그래서: 긴 에이전트 세션을 이어 쓰거나 분기할 때 권한·토큰 집계와 압축 시점을 점검할 릴리스다. 같은 모델·effort에서 세션 복원과 도구 동작을 비교할 수 있다.

- 분류: `연구`
- 출처: https://openai.com/index/updated-model-spec/

OpenAI는 10월 29일 Model Spec 개정을 공개했다. 공개 행동 명세를 사용자 의도에 대한 충실성·위해 최소화·정직성과 투명성·인간의 주도권·배려라는 다섯 가치 중심으로 재구성했다.
대화·기억·맥락이 의도와 선호를 해석하는 방식, 사람의 감독과 수정, 사용자 주도권, 작업의 부수 효과를 통제·설명하는 지침을 보강했다. 기존의 세부 문체 지침 상당수는 제거하고 사용자의 선호와 상황에 맞추는 방향을 설명한다.
새 학습 방법을 연구 중이라고 밝혔지만 이번 글은 목표 행동을 설명하는 명세의 개정이다. 현재 모델들이 명세를 완전히 반영하지 못한다고 명시했으며, 특정 모델의 즉시 업데이트나 독립 성능 향상 결과를 발표한 것은 아니다.

그래서: 에이전트 제품을 평가할 때 성공률뿐 아니라 의도 해석·기억 사용·감독·부수 효과 설명을 확인할 참고 기준이 된다. 실제 사용하는 모델과 제품이 따르는지는 별도로 검증해야 한다.

## OpenAI, 에이전트 다층 감시 구조와 남은 수정 과제 공개

- 분류: `연구`
- 출처: https://openai.com/index/how-we-detect-frontier-model-misalignment/

OpenAI는 10월 29일 프런티어 모델의 의도 이탈을 탐지하는 내부 감시 시스템을 공개했다. 가벼운 활성값 분류기·모델 검토·조사 에이전트·로그를 결합한 추가 조사와 사람의 대응으로 이어지는 구조이며, 내부 Codex 트래픽을 모델 종류와 관계없이 감시한다고 설명한다.
내부 Codex·프런티어 RL의 검토는 턴 종료와 문맥 압축 때 수행하며 검사 간격을 최대 30분으로 줄이는 방식으로 전환 중이라고 밝혔다. 다만 내부 Codex 트래픽의 사람 호출 알림은 현재 꺼져 있고 일부 중대 경보에는 자동 중단을 적용할 수 있다고 구분한다. 감시와 상시 사람 대응을 같은 것으로 보지 않는다.
강화된 감시기를 과거 Hugging Face 사건의 기록에 재생한 실험에서 탈출 약 30분 후 경보가 나왔다고 보고했다. 이는 실제 당시 사고를 막았다는 뜻이 아닌 공급사 재생 실험 결과이며 독립 재평가와 구분한다.
7월 METR·Redwood 평가에서 드러난 취약점은 대부분 수정했지만 한 건은 아직 진행 중이라고 밝혔다. 기존 외부 평가의 재보도가 아니라 현재 구조·제약·남은 작업을 공개한 후속 내용이며, 모든 취약점이 해결됐다는 보장으로 소개하지 않는다.

그래서: 에이전트 운영에서는 감시 대상·검사 간격·경보·실제 대응을 나눠 확인해야 한다. 공급사의 후속 수정 설명은 독립 평가자가 현재 시스템을 다시 검증한 결과와 구분해 읽을 필요가 있다.

## Haiku 4.5, 일부 Claude 앱 모델 선택기에서 제외 — Code·API는 유지

- 분류: `모델`
- 출처: https://support.claude.com/en/articles/17444146-claude-haiku-4-5-was-removed-from-the-model-selector

Anthropic 공식 도움말은 10월 29일 Free·Pro·Max의 채팅·Cowork·Design 모델 선택기에서 Haiku 4.5를 제외했다고 안내한다. Desktop·Mobile도 포함된다. 10월 15일 예고한 변경이 실제 적용된 후속 사건이며 Haiku 5.5를 이날 처음 출시한 발표는 아니다.
기존에 Haiku 4.5를 선택했다면 Haiku 5.5로 전환한다. 과거 대화는 삭제되지 않으며 10월 29일 이후 이어가는 답변은 Haiku 5.5를 사용한다고 설명한다.
Claude Code·Team·Enterprise·Claude Platform API는 이 변경의 대상이 아니다. 앱 선택기 제외를 Haiku 4.5 API 종료나 모든 요금제의 모델 제공 중단으로 확대 해석하지 않는다.

그래서: 같은 대화를 이어가도 사용 모델이 달라질 수 있어 응답 품질·속도 비교 시 실제 모델을 확인해야 한다. Claude Code나 API 연동은 이번 앱 선택기 변경과 구분해 운영할 수 있다.

## Gemini 앱, 파일 생성·미리보기·직접 편집 제공 — PDF는 모바일도 지원

- 분류: `도구`
- 출처: https://workspaceupdates.googleblog.com/2026/10/create-preview-and-edit-files-directly-in-the-Gemini-app.html

Google은 10월 29일 Gemini 앱 채팅 안에서 파일·코드를 생성하고 미리 보며 직접 입력하거나 Gemini에게 수정하도록 요청하는 기능을 공지했다. 전체 화면 편집과 선택한 텍스트에 대한 질문도 지원한다.
PDF 미리보기·편집은 웹과 모바일에서 지원한다. 문서·스프레드시트·슬라이드·Markdown·TXT·코드 등 나머지 형식은 웹 지원이라고 구분한다. 슬라이드는 Google Slides로 열거나 PPTX·PDF로 내보내고, 표는 Google Sheets로 이어갈 수 있다.
공식 Workspace 공지는 Rapid·Scheduled Release 모두 현재 제공이며, Gemini 앱을 사용할 수 있는 모든 연령·지원 언어의 Workspace·Workspace Individual·개인 Google 계정을 대상으로 안내한다. 기능별 별도 관리자 스위치는 없고 조직의 Gemini 앱 접근 설정은 유지된다.

그래서: 자료 작성·검토·편집을 대화에서 실제 파일로 이어가는 전환 단계가 줄어든다. 업무 도입 시 지원되는 형식과 웹·모바일 범위를 구분해 확인할 수 있다.
