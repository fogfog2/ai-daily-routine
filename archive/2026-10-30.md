## Claude Code 2.1.314 — 관리자 effort 제한 복구·작업 폴더 밖 쓰기 차단

- 분류: `도구`
- 출처: https://github.com/anthropics/claude-code/releases/tag/v2.1.314

Anthropic은 10월 30일 01:06:26 UTC, 한국시간 10월 30일 10:06에 Claude Code 2.1.314 안정판을 공개했다. 관리자가 모델의 effort 상한을 낮춘 경우 Invalid effort level 오류가 반복되던 문제를 수정해 허용 수준으로 낮춰 재시도하고 실제 사용하는 수준을 알린다.
permissions.blockWritesOutsideWorkingDirectories 설정을 추가했다. 켜면 모든 권한 모드에서 Write·Edit·NotebookEdit가 작업 디렉터리 밖의 경로를 거부한다. 모든 셸 명령까지 차단하는 설정으로 확대 해석하지 않는다. 재개한 worktree에 샌드박스가 적용되지 않던 문제도 수정했다.
VS Code·Claude Desktop Code 탭에서는 20만 토큰 이상 대화를 유휴 상태에서 요약하고, 다음 메시지 때 프롬프트 캐시가 만료돼 있으면 그 요약을 사용한다. 압축·캐시·비용을 확인할 변화이며 모델의 문맥 창 확대 발표는 아니다.
claude -p 시작 실패를 무출력·종료 코드 0 대신 오류·코드 1로 보고하도록 고쳤다. 대규모 하위 에이전트 작업의 부모 메모리 사용과 손상된 기록 재개도 개선했다. 새 모델의 독립 성능 평가나 effort별 속도 향상을 측정한 결과는 아니다.

그래서: Claude·Codex를 비교할 때 선택한 effort와 실제 적용 수준을 함께 남겨야 한다. 자동화에서는 종료 코드·작업 폴더·유휴 압축을 확인하면 실패를 성공으로 처리하거나 예상 밖 파일을 수정하는 일을 줄일 수 있다.

## Opus 4.8 Fast mode, 11월 30일 종료 예고 — Opus 5.5로 이전 권고

- 분류: `모델`
- 출처: https://platform.claude.com/docs/en/build-with-claude/fast-mode

Anthropic은 10월 30일 릴리스 노트에서 Claude Opus 4.8의 Fast mode를 deprecated로 지정하고 2026년 11월 30일 제거한다고 공지했다. 예고일과 실제 종료일을 구분하며, 10월 30일에 이미 중단됐다고 소개하지 않는다.
제거 후 claude-opus-4-8에 speed: "fast"를 지정한 요청은 오류가 된다. 계속 Fast mode를 쓰려면 Opus 5.5로 이전하라고 안내한다. 이 공지는 Opus 4.8 일반 속도의 전체 모델 종료를 뜻하지 않는다.
Opus 5.5 Fast mode는 이미 정식 제공 중이고 Opus 5·4.8의 기존 Fast mode는 연구 미리보기다. Fast mode는 추론 서비스 속도 설정으로, 응답에 쓰는 토큰과 깊이를 조절하는 effort와 구분한다. 이번 공지에 새 단가 인하나 독립 벤치마크 결과는 없다.

그래서: Opus 4.8 Fast mode를 고정한 에이전트는 종료 전에 모델·speed 설정과 오류 처리를 옮겨야 한다. Claude·Codex 비용·속도 비교에서는 모델 버전·effort·서비스 속도를 각각 기록할 수 있다.
