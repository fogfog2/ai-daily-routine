## Codex의 GPT-5.5 종료 — 한국시간 10월 15일 적용

- 분류: `도구`
- 출처: https://learn.chatgpt.com/docs/changelog

ChatGPT 계정으로 로그인한 Codex의 GPT-5.5 지원이 미국 태평양시간 10월 14일 정오, 한국시간 10월 15일 오전 4시에 종료된다. 공식 변경 기록의 게시일은 10월 14일이다.
OpenAI API와 API 키로 인증한 Codex 세션은 이번 종료 대상이 아니다. 공식 안내는 요금제와 클라이언트에서 사용할 수 있다면 GPT-6.1 Sol로 전환하도록 권고한다.
워크스페이스 기본 모델, 저장된 설정, 커스텀 에이전트, 예약 작업과 스크립트에 gpt-5.5가 남아 있는지 확인할 필요가 있다.

그래서: 예약 실행이 예전 모델을 계속 지정하고 있다면 다음 실행 전에 모델 설정을 확인할 시점이다.

## Codex CLI 0.163.0 — 실행 중 지시·설정 검색·도구 병렬 조회

- 분류: `도구`
- 출처: https://github.com/openai/codex/releases/tag/rust-v0.163.0

OpenAI는 10월 15일 Codex CLI 0.163.0을 공개했다. 10월 20일 확인 시 최신 안정 릴리스이며, 응답 중 후속 메시지로 방향을 바꾸고 턴 중단 시 실행 중인 Code Mode 셀과 중첩 도구 호출도 멈춘다.
/config에서 설정을 검색·변경하고 재시작 필요 여부를 확인할 수 있다. 스킬·메모리·대화 이력 등 서로 독립적인 읽기 전용 도구는 병렬로 조회한다.
저장된 스레드를 재개할 때 현재 관리 정책과 명시적 재정의를 지키면서 권한·네트워크 승인을 복원한다. /daemon으로 관리형 백그라운드 서버를 재시작하고 자동 재연결하는 기능도 추가했다.

그래서: 긴 에이전트 작업을 실행 중에 조정하고, 재개·설정 변경 과정의 마찰을 줄이는 운영 개선이다.

## Claude Opus 5.5 Fast mode 정식 제공 — 베타 헤더 제거

- 분류: `도구`
- 출처: https://platform.claude.com/docs/en/release-notes/overview

Anthropic은 10월 15일 Claude Opus 5.5 Fast mode를 연구 미리보기에서 정식 제공으로 전환했다. 별도 접근 신청과 fast-mode-2026-02-01 베타 헤더가 더 이상 필요하지 않다.
Start·Build·Scale 사용량 등급에 기본 Fast mode 속도 제한을 제공하며, 기존 헤더를 보내는 요청도 계속 동작한다. Opus 5·Opus 4.8 Fast mode는 연구 미리보기와 베타 헤더 요구가 유지된다.

그래서: Opus 5.5 에이전트의 지연 시간을 줄이는 옵션을 더 쉽게 적용할 수 있지만, 속도 옵션 자체를 벤치마크 품질 향상으로 해석하지 않는다.
