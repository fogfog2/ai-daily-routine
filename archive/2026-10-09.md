## Codex CLI 0.162.1 — 비동기 질문·백그라운드 서버 시작 오류 수정

- 분류: `도구`

그래서: 질문 응답이나 재연결 과정에서 CLI가 중단됐던 사용자가 확인할 유지보수 패치다.

## Claude Managed Agents 동적 워크플로 — 여러 에이전트를 단계별 실행

- 분류: `도구`
- 출처: https://platform.claude.com/docs/en/release-notes/overview

Anthropic은 10월 9일 Claude Managed Agents의 dynamic workflows 베타를 발표했다. 수백 개 문서 검토처럼 여러 조각으로 나뉜 작업에서 에이전트가 워크플로 프로그램을 작성하고 서버가 백그라운드로 실행한다.
프로그램은 여러 에이전트를 단계별로 실행하고 결과를 결합한다. multiagent 설정에서 workflows를 활성화하고, 시스템 프롬프트로 시작 조건을 안내하며 workflow_run.* 이벤트로 진행 상황을 추적한다.

그래서: 대량 병렬 작업을 개별 호출로 직접 조립하는 대신 관리형 워크플로로 실행할 수 있는 선택지가 생겼다.
