앞선 11-20 session 집계 규칙 변경도 점진 적용이며 API가 채팅별 적용 규칙을 표시하지 않는다. 따라서 과거 지표의 재계산·session/chat 분류 변화와 실제 사용자 증가를 분리해야 한다. 이 API는 활동 분석이고 모델 benchmark 정확도·Claude API token 요금 자체의 변경 발표가 아니다.

그래서: 비용·도입 효과 대시보드의 급증을 agent 성능이나 사용량 증가로 바로 해석하면 안 된다. 적용 UTC 날짜 이후를 다시 조회하고 집계 규칙과 수정 전후 snapshot을 함께 보관할 근거가 생겼다.

## ChatGPT 채팅용 GPT-6.2 Sol 배포 — Work·Codex 모델 변경과 구분

- 분류: `도구`
- 출처: https://help.openai.com/en/articles/6825453-chatgpt-release-notes

OpenAI는 11-23 Chat 탭에 일상 대화용으로 조정한 GPT-6.2 Sol 버전을 Plus·Pro·Business·Enterprise에 전 세계 점진 배포한다고 발표했다. Enterprise는 관리자 설정에 따른다. 이 배포로 Work·Codex의 모델이 바뀌는 것은 아니며 11-17의 Astra·Sol 최초 발표를 다시 수록한 것도 아니다.
공급사 내부 Chat 평가에서 이미지 이해는 GPT-6의 47.4% 대비 71.7%, 어려운 instruction following은 62.5% 대비 78.1%라고 보고했다. 평가셋·제품 맥락이 다른 CLI benchmark나 독립 평가와 같은 점수로 합치지 않는다.
측정한 가장 낮은 reasoning 설정의 내부 expert-level 과제 점수는 52%→65%, 내부 BrowseComp의 Extra high에서는 54.4%→64.5%라고 밝혔다. Chat UI의 Extra high·최저 측정 설정을 Codex/Claude의 동일 effort나 API flag로 자동 대응하지 않으며 모든 모델의 비용·완료 시간 비교 자료도 아니다.
이번 변경은 정보 검색·복잡한 지시·후속 제안의 대화 동작을 개선했다는 공급사 설명이다. 11-24 API changelog의 chat-latest snapshot 갱신은 별도 후속 기록이며 날짜 없는 alias가 고정된 production 모델 버전을 뜻하지 않는다. API 문서는 production에 GPT-6.2 계열을 권한다. API 날짜 근거: https://developers.openai.com/api/docs/changelog

그래서: Chat과 Work·Codex에서 같은 GPT-6.2 이름을 보더라도 배포 경로·대화 조정·평가 조건은 구분해야 한다. Chat 내부 개선을 곧바로 코딩 agent 전체 성능 상승으로 해석하지 않는다.
