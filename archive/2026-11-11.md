## Gemini Decisions API 제공 시작 — 멀티모달 선택·채점과 입력 토큰 과금

- 분류: `도구`
- 출처: https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/

Google은 11-11 Gemini API·AI Studio에서 Gemini Decision 1(gemini-decision-1)을 쓰는 Decisions API를 발표했다. 텍스트·이미지·음성·영상·PDF에서 고정 후보를 평가하는 용도이며, Google Cloud 지원은 추후라고 구분했다.
yes/no·다지선다·순서형 루브릭 채점을 한 요청에 최대 1,000개 독립 질문으로 처리한다. 공식 가이드의 전체 문맥 한도는 공유 입력과 질문을 합쳐 262,144토큰이며 질문끼리 서로의 답을 볼 수 없다. 자유 형식 답변을 생성하는 범용 대화 API와 다르다.
요금은 입력 100만 토큰당 $0.10·출력 토큰 $0이며 프로토타입용 무료 티어도 제공한다. 공유 입력은 요청당 한 번 과금하지만 각 질문의 지시·후보 토큰은 추가된다. 질문을 늘려도 모든 입력이 무료라는 뜻은 아니다.
공급사는 최대 16K 문맥·요청당 1~100개 질문 조건에서 모델 연산 중앙 지연 50~100ms, 종단 간 150~250ms를 제시했다. 독립 측정치나 최대 문맥·1,000질문 전체에 대한 속도 보장이 아니며, 반환 confidence도 성공을 보장하는 값은 아니다.

그래서: 에이전트의 도구 선택·모델 및 thinking 수준 라우팅·문맥 채점을 생성 호출과 분리할 선택지가 생겼다. 실제 입력 분포에서 정확도·신뢰도·지연을 측정하고 애매한 경우 큰 모델이나 사람에게 넘기는 흐름을 설계할 수 있다.

## Databricks Genie 기업 데이터 평가 — 업무 문맥 효과와 비대칭 도구 조건 공개

- 분류: `연구`
- 출처: https://www.databricks.com/blog/genie-genie-ontology-delivers-16-accuracy-less-half-tokens

Databricks는 11-11 Turing과 만든 기업 데이터 에이전트 벤치마크 결과를 공개했다. 가상 에너지 회사의 실제 Databricks 작업 공간에 표·노트북·대시보드·저장 SQL·문서와 오래된 작업물을 넣어 업무 정의·과거 규칙을 찾아야 하는 질문을 평가했다.
각 에이전트에 같은 질문을 주고 작업당 5회 실행했다. 공급사는 통과율 Genie 91%·Agent A 45%·Agent B 58%, Genie의 평균 토큰 사용 절반 미만과 실행 시간 3~4배 단축을 보고했다. 자체 제품 공급사가 발표한 조건부 결과이며 독립적인 Claude·Codex 모델 순위가 아니다.
Genie는 네이티브로 실행했고 다른 두 에이전트는 Databricks toolbelt로 연결했다. 비교 도구에서 Genie MCP를 의도적으로 제외했으며 상대 에이전트의 모델명·effort는 공개하지 않았다. 동일 모델·effort·하네스 비교로 해석할 수 없다.
평가 재현 자료는 공개 다운로드 링크 대신 담당 계정 팀에 접근을 요청하도록 안내한다. 원문도 업무 지식이 축적되지 않은 신규 환경이나 표·스키마만으로 풀리는 문제에서는 격차가 작아질 수 있다고 한정했다. Genie Ontology의 기존 GA 상태를 이번 날짜의 신규 출시로 바꾸지 않았다.

그래서: 모델 선택 외에 업무 정의·과거 SQL·근거 문서를 찾아주는 문맥 계층이 성능에 큰 영향을 줄 수 있다. 공급사 수치만으로 선호 모델을 바꾸기보다 같은 데이터·도구 권한에서 재현하는 것이 유용하다.
