## Claude Code mods — 프롬프트·도구·권한 흐름을 TypeScript로 확장

- 분류: `도구`
- 출처: https://claude.com/resources/articles/claude-code-mods

Anthropic은 10월 1일 Claude Code mods를 소개했다. TypeScript 함수로 프롬프트, 사용자 인터페이스, 기본 도구와 새 기능을 바꾸며 플러그인을 통해 CLI와 데스크톱에 배포한다.
이벤트 전후 또는 대체·감싸기 방식으로 프롬프트 수정, 도구 호출 차단·재작성·재시도, 권한 승인·거부, 도구 출력 가리기 등을 구현할 수 있다.
mods는 샌드박스에서 실행되지 않고 Claude Code와 같은 머신 접근 권한을 가진다. 관리형 Team·Enterprise의 sec-default는 먼저 로드되어 위험한 사용자 mod 동작을 제한한다.

그래서: 반복되는 팀 개발 규칙을 에이전트 동작에 반영할 수 있으며, 실행 코드의 출처와 조직 정책을 함께 관리해야 한다.

## Codex CLI 0.160.0 — 에이전트 인계·서브에이전트·재연결 개선

- 분류: `도구`
- 출처: https://github.com/openai/codex/releases/tag/rust-v0.160.0

OpenAI는 10월 1일 Codex CLI 0.160.0을 공개했다. 선택적으로 사용하는 Guardian 검토가 이전 사용자 지시와 에이전트 인계 맥락을 가져올 수 있도록 확장했다.
서브에이전트는 시작 중인 실행 환경을 유지하고 환경 설정·준비 실패를 전달받도록 수정됐다. 연결 복구 후에는 제출 여부가 불확실한 메시지를 먼저 정리한 뒤 미전송 대기 메시지를 재개해 중복 전송을 방지한다.
터미널 UI의 세션 재개·분기에서 provider, reasoning-summary, verbosity 설정과 기록 표시를 보존하는 수정도 포함됐다.

그래서: 여러 에이전트의 인계와 긴 작업의 재연결 안정성을 개선한 릴리스이며, 모델 자체의 벤치마크 점수 향상과는 별개의 변경이다.
