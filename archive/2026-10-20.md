## OpenAI API, 12시간 프롬프트 캐시 제공 — 긴 간격의 반복 입력 재사용

- 분류: `시스템`
- 출처: https://developers.openai.com/api/docs/guides/prompt-caching

OpenAI는 10월 20일 API 변경 기록에서 12시간 프롬프트 캐싱을 발표했다. 지원하는 Responses API 모델에서 공통 지시·도구·문맥을 긴 간격의 요청 사이에도 재사용하는 선택지다.
12시간 캐시 쓰기는 일반 입력 토큰 가격의 2.5배다. 공식 문서는 GPT-5.6 이후 지원 모델의 기본 30분 쓰기를 1.25배, 읽기는 대부분 0.1배·GPT-6.1 Sol은 0.05배로 안내한다.
최소 캐시 수명은 캐시 읽기 가격의 적용 자격을 다루며, 모든 요청에서 저장된 KV 재사용이나 낮은 지연을 보장하지 않는다. 적용 모델·공통 접두부·실제 사용량과 쓰기 비용을 함께 확인해야 한다.

그래서: 같은 문맥을 하루 동안 반복 사용하는 에이전트는 절감을 검토할 수 있지만, 재사용이 적으면 높은 캐시 쓰기 비용이 이득을 상쇄할 수 있다.
