## Claude Platform, Google Cloud에서 Anthropic 관리형으로 정식 제공

- 분류: `도구`
- 출처: https://claude.com/resources/articles/claude-models-on-google-cloud-anthropic-managed

Anthropic은 10월 22일 Claude Models on Google Cloud (Anthropic managed)의 일반 제공을 발표했다. Anthropic이 운영하는 Claude API에 Google Cloud 프로젝트를 통해 접근하며, 기존 Google 관리형 제공도 유지된다.
Google Cloud IAM 인증과 Marketplace 청구를 사용하고, Claude 사용액을 기존 Google Cloud 사용 약정에 반영할 수 있다. 현재 엔드포인트는 US·Global이다.
Claude Platform의 새 기능과 베타를 네이티브 플랫폼 공개일에 함께 제공한다고 안내했다. 공식 문서는 Opus 5.5 Fast mode 지원도 명시하지만, 제한된 베타는 별도 접근 자격이 필요하다.

그래서: Google Cloud를 쓰는 조직은 인증·청구를 유지하면서 Claude API 신기능을 도입하는 경로를 선택할 수 있으며, Anthropic 관리형과 Google 관리형의 지원·운영 조건을 구분해야 한다.

## Anthropic, 서브에이전트를 스킬·도구로 통합하는 평가 중심 가이드 공개

- 분류: `도구`
- 출처: https://claude.com/resources/articles/building-agents-when-to-fold-subagents-into-your-main-agent-loop

Anthropic은 10월 22일 일부 라우터·플래너·도메인 서브에이전트를 단일 에이전트 루프로 통합하는 설계 가이드를 공개했다. 필요한 스킬·도구만 점진적으로 불러오는 방식을 제안한다.
여러 기업 배포 비교에서 품질·비용·지연 개선을 자주 관측했다는 공급사 설명이다. 보편적 벤치마크 승리나 모든 다중 에이전트 구조의 대체를 입증한 결과는 아니며, 병렬 작업·독립 검증·컨텍스트 분리가 필요한 서브에이전트는 유지 대상으로 설명한다.
동반 공개한 anthropics/single-agent-loop-kit은 동일한 평가로 변경 전후를 비교하는 참조 구현이다. 저장소는 유지보수·기여 접수를 하지 않는다고 명시하며, 실제 모델 검증 범위도 예제의 일부 실행으로 제한해 공개한다.

그래서: 에이전트 수를 늘리는 것만으로 성능을 기대하기보다, 작업 완료율·비용·지연을 같은 조건에서 측정하고 한 구성씩 바꿀 근거가 생겼다.

## OpenAI Decisions API 정식 제공 — Luna 판단 요청당 질문 400개 지원

- 분류: `도구`
- 출처: https://developers.openai.com/api/docs/changelog

OpenAI는 10월 22일 gpt-6-luna 기반 Decisions API의 일반 제공을 발표했다. 10월 6일 공개 베타 이후 제공 단계와 기능이 바뀐 후속 소식이다.
요청당 질문 한도를 베타의 200개에서 400개로 늘렸다. 공통 입력의 프롬프트 캐싱, 질문별 지시의 이미지, input_json을 통한 구조화 데이터 입력도 지원한다.
현재 지원 모델은 gpt-6-luna다. 텍스트·이미지·JSON에서 조건 확률·선택·점수를 얻는 API이며, Codex CLI의 새 버전이나 다른 모델의 effort별 성능 향상 발표와는 구분한다.

그래서: 반복 분류·라우팅·평가처럼 많은 판단을 묶는 에이전트 흐름에서 호출 구성과 캐시 사용을 재검토할 수 있다.
