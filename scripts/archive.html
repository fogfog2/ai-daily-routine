01

기초 모든 모델의 밑바닥 부품

구조를 논하기 전에 이미 정해져 있는 것들. 눈에 잘 띄지 않지만 되돌리기는 가장 어렵다.

Tokenization

글자와 단어 사이에서 타협하다

BPE가 빈도만 세어 형태소를 찾아내는 과정, 그리고 한국어가 비싼 구조적 원인.

Normalization

분포를 붙잡아 학습을 안정시키다

평균을 어느 축으로 내느냐가 배치 의존성과 추론 동작을 가른다. Pre-LN과 RMSNorm.

Embeddings & Positional Encoding

토큰이 벡터가 되고 순서를 얻기까지

어텐션은 순서를 모른다. 위치를 더할 것인가 회전시킬 것인가 — 정현파에서 RoPE까지.

Backpropagation & Optimizers

학습이 실제로 도는 방식

연쇄 법칙의 계산 순서가 만든 역전파, 그리고 Adam에서 AdamW로 옮겨간 한 줄.
02

아키텍처 무엇을 쌓을 것인가

어텐션을 축으로 한 구조와 그 변형들. 언어에서 출발해 이미지로, 그리고 조건부 연산으로.

Transformer

모든 단어가 서로를 바라보다

셀프 어텐션이 문장 속 모든 단어를 동시에 저울질하는 방식. 현대 LLM의 뼈대.

Vision Transformer

이미지를 단어처럼 자르다

비전 전용 구조를 걷어낸 대가와 보상 — 편향은 시작점을 높이고 천장을 낮춘다.

Mixture of Experts

필요한 전문가만 깨우는 신경망

top-k 라우팅으로 파라미터 수와 토큰당 연산량을 분리하는 구조.

RNN & LSTM

순서대로 읽던 시절

셀 상태가 그래디언트를 살린 방식과, 어텐션이 이긴 진짜 이유인 순차성 병목.

Mamba & State Space Models

다시 순서대로, 그러나 빠르게

입력에 따라 변하는 상태공간 모델. 선형 스케일링을 얻고 무엇을 내주었는가.

Autoencoders & VAE

압축이 만들어낸 잠재공간

재구성만 시켰더니 의미가 생긴 이유, 그리고 확산 모델이 올라탄 그 공간.

Graph Neural Networks

격자도 수열도 아닌 데이터

이웃에게 메시지를 받아 자신을 갱신하는 구조. 층을 쌓을수록 뭉개지는 문제까지.
03

학습 어떤 과제로 가르칠 것인가

사전학습 과제의 설계가 곧 얻어지는 능력을 정한다. 그리고 얼마나 키울지의 경제학.

BERT & Masked LM

빈칸을 메우며 언어를 익히다

양방향 학습을 막던 제약을 구조가 아니라 과제 교체로 푼 방법.

Diffusion Models

잡음 속에서 그림을 꺼내다

노이즈를 더하는 과정을 거꾸로 되돌리는 법을 배워 이미지를 꺼내는 원리.

CLIP

그림과 말을 같은 공간에 놓다

이미지와 텍스트를 하나의 임베딩 공간에 놓아 제로샷 분류를 가능하게 한 학습.

Scaling Laws

크기와 데이터의 최적 배분

같은 관측에서 정반대 처방이 나온 이유. Chinchilla의 20:1과 그것을 어기는 근거.

Self-Supervised Learning

라벨 없이 배우는 법

데이터 자신이 정답이 되는 과제 설계. 대조학습과 붕괴를 피하는 장치들.

GAN

두 신경망을 맞붙이다

판별자를 손실 함수로 쓴 발상, 그리고 확산 모델에 자리를 내준 이유.

데이터 품질과 커리큘럼

무엇을 먹이느냐가 정한다

중복 제거와 필터링이 파라미터를 늘리는 것보다 싸게 먹히는 구간.
04

적응·정렬 학습된 모델을 길들이기

전부 다시 학습하지 않고 방향만 바꾸는 방법들.

LoRA

얼린 가중치 옆에 샛길을 내다

ΔW를 저랭크로 쪼개 학습 파라미터를 0.06%로 줄이는 법.

RLHF

선호를 손실 함수로 번역하다

선호 쌍을 보상으로 바꾸고, 끝내 보상 모델을 소거해 버린 DPO의 유도까지.

Instruction Tuning

지시를 따르게 만들기

다음 단어를 맞추던 모델이 부탁을 알아듣게 되는 단계. 정렬의 첫 관문.

DPO

보상 모델을 지워버린 정렬

RLHF의 최적해를 역산해 강화학습 없이 같은 목표에 도달하는 유도.

PEFT — Adapter·Prefix·IA³

LoRA 말고도 있는 길

어디에 무엇을 끼워넣을지의 선택지 비교. 추론 지연이 갈리는 지점.

Constitutional AI

사람 라벨 대신 원칙

모델이 자기 답을 원칙에 비춰 고치게 하는 방식. RLAIF의 실체.
05

추론 최적화 같은 모델을 싸고 빠르게

품질을 내주지 않고 비용과 지연을 줄이는 기법들. 대부분 병목이 연산이 아니라 메모리라는 관찰에서 출발한다.

FlashAttention

어텐션을 메모리 계층에 맞춰 다시 쓰다

병목이 FLOPs가 아니라 HBM 왕복이었다는 것. 타일링과 온라인 소프트맥스.

KV Cache & PagedAttention

문맥을 페이지로 관리하다

GPU 메모리의 60~80%를 낭비하던 구조를, OS의 페이징을 빌려 4% 미만으로.

Speculative Decoding

초안을 쓰고 한 번에 검산하다

작은 모델의 초안을 채택해도 출력 분포가 수학적으로 보존되는 이유.

Quantization

정밀도를 깎아 모델을 옮기다

4비트에서도 버티는 이유는 목표를 바꿨기 때문. GPTQ와 AWQ.

Knowledge Distillation

큰 모델의 판단을 옮겨 담다

정답 대신 큰 모델의 확률 분포를 배우게 하는 것이 왜 더 나은가.

Pruning & Sparsity

쓰지 않는 연결을 잘라내다

비정형 희소성이 이론상 이득을 실제 속도로 바꾸지 못하는 이유. 2:4 구조적 희소성.
06

학습 인프라 어떻게 굴리는가

한 장의 GPU에 담기지 않는 모델을 실제로 학습시키는 공학. 무엇을 쪼개고 무엇을 다시 계산할지의 선택.

분산 학습 — DP·TP·PP

한 장에 담기지 않을 때

데이터·텐서·파이프라인 병렬의 분담과 통신량. ZeRO가 줄인 중복.

Mixed Precision

16비트로 학습하기

fp16이 언더플로로 무너지는 지점과 loss scaling, 그리고 bf16이 이긴 이유.

Gradient Checkpointing

메모리를 연산으로 사다

활성값을 버리고 필요할 때 다시 계산하는 거래. √n 지점의 유래.
07

응용·시스템 실제로 쓰이는 형태

모델을 바깥 세계에 연결하는 패턴. 지식을 밖에 두고, 도구를 쥐여 주고, 여러 요청을 한 장비에 태운다.

RAG

모델 밖에 기억을 두다

지식을 가중치에서 꺼내 외부로 옮기는 선택과 그 대가.

Model Context Protocol

도구를 모델에 꽂는 규약

호스트·클라이언트·서버 구조와 프리미티브. 상태를 버린 2026-07-28 개정.

In-Context Learning

가중치를 건드리지 않는 학습

예시 몇 개로 새 과제를 하는 현상. 무엇을 배우는 게 아니라 무엇을 고르는가.

Chain-of-Thought

생각할 시간을 주다

중간 과정을 쓰게 했더니 정답률이 오른 이유, 그리고 추론 시간 스케일링.

AI Agents & Tool Use

모델에 손을 달아주다

관측·결정·행동의 순환. 언제 에이전트가 필요하고 언제 과한가.

LLM 서빙 — 배칭과 스케줄링

한 장비에 여러 요청을 태우다

연속 배칭이 처리량을 끌어올리는 원리와 지연·처리량의 맞바꿈.
08

평가·안전 잘 됐는지 어떻게 아는가

만드는 이야기가 끝나면 남는 질문. 무엇을 재고 있는지, 왜 틀리는지, 어디가 뚫리는지, 안을 들여다볼 수 있는지.

평가와 벤치마크

무엇을 재고 있는가

점수가 오르는 것과 능력이 오르는 것의 차이. 오염과 포화, 그리고 대안.

환각

왜 그럴듯하게 틀리는가

구조에서 비롯된 원인과, 완화가 제거를 뜻하지 않는 이유.

Prompt Injection

데이터가 명령이 되는 순간

지시와 데이터를 구분하지 못하는 구조적 취약점. 에이전트에서 커지는 위험.

해석가능성

안을 들여다볼 수 있는가

중첩 때문에 뉴런 하나가 여러 뜻을 갖는 문제와, 희소 오토인코더의 접근.
09

특집 — 객체 검출 손으로 정하던 것을 하나씩 학습으로

검출기 계보를 순서대로 읽는 특집. 영역 제안 → 앵커 → 라벨 할당 → NMS가 차례로 학습에 흡수되는 과정이고, 마지막이 현재 도달점인 RF-DETR이다. 위에서부터 읽도록 배열했다.

① Object Detection 계보

2단계에서 1단계로

가변 개수 출력이라는 난점, 제안 단계를 없앤 과정, Focal Loss가 푼 클래스 불균형.

② YOLO 계보

v5에서 YOLO26까지

버전 번호의 혼란을 정리하고, 앵커·NMS를 하나씩 없앤 과정과 라이선스 갈림.

③ DETR 계보

검출을 집합 예측으로

헝가리안 매칭으로 중복을 원천 차단한 발상과, 실용화까지 걸린 5년.

④ RF-DETR

실시간 검출의 현재 도달점

실시간 최초 60 AP. DINOv2 백본의 이점과 CPU 경로 부재라는 대가, 이전 판단 기준.

＋ YOLOv5 (심화)

격자 위에 앵커를 놓다

앵커 디코딩 공식, 이웃 칸까지 쓰는 정적 라벨 할당, 그리고 모델 스케일링.

＋ YOLOX (심화)

앵커를 걷어내고 머리를 나누다

성능을 끌어올린 것이 왜 백본이 아니라 라벨 할당이었는지.
