첫 세 편의 원문과 장면별 대사는 각 에피소드 JSON에서 관리한다. 영상·자막·시간표 대본·비교 도식은 공개 사이트의 `media/vision/<id>/`에 함께 들어간다. 입력 장면은 합성 예시이며 실측 그래프는 논문 또는 개발사의 공개 수치를 사용한다.

## 후속 두 편의 스토리보드

**LoMa** · 0–20초에 반복 무늬 속 같은 모서리와 한 칸 옆의 모서리를 표시한다. 20–55초에 두 영상의 점 사이에 대응선을 그리며 모호한 질감과 넓은 문맥을 비교한다. 55–100초에는 손으로 대응을 표기한 HardMatch의 평가 방식을 설명하고 허용 오차 원의 반경에 따라 PCK가 바뀌는 예를 계산한다. 100–135초에는 같은 대응의 픽셀 오차와 상대 포즈의 각도 오차를 함께 본다. 합성 예와 벤치마크 값을 구분한다. [연구진의 모델 및 평가 자료](https://www.davnords.com/loma)

**EndoStreamDepth** · 0–20초에 같은 지점의 깊이가 프레임 사이에서 흔들리는 합성 시퀀스를 연다. 20–65초에 다중 스케일의 Mamba 상태가 프레임마다 갱신되는 경로를 표시한다. 65–100초에는 현재 관측과 이전 상태를 이어 깊이 궤적을 그린다. 100–125초에는 단일 프레임의 깊이 정확도와 시간적 안정성을 서로 다른 평가 항목으로 읽는다. 합성 깊이 궤적에는 설명용 표기를 넣는다. [MIDL 논문](https://proceedings.mlr.press/v315/li26f.html)

## 재생성

Node.js, FFmpeg, 한글 글꼴(Noto Sans CJK KR), Python 환경에 Supertonic 1.3.1과 로컬 Supertonic 3 모델이 필요하다. 제작 음성은 한국어 F2다. Remotion이 지원하는 Chrome을 직접 지정할 때는 `REMOTION_BROWSER`에 실행 파일 경로를 설정한다.

```sh
npm install
python -m pip install 'supertonic==1.3.1' soundfile numpy
python voice.py /path/to/supertonic-3 /tmp/vision-work endoda3 rf-detr-atto mobile-int8-sr
node render.cjs /tmp/vision-work ../../site-pages/media/vision endoda3 rf-detr-atto mobile-int8-sr
```

`voice.py`는 문장별 음성을 작업 디렉터리에 캐시한다. 대사가 바뀐 문장은 다시 합성한다. 장면 안에서는 문장별 발화 길이에 맞춰 자막을 배치하고, 장면 전체는 편집 시간표에 맞춘다. 영상은 720×1280 H.264/AAC이며 한국어 자막을 영상에 표시한다. WebVTT와 시간표 대본도 따로 제공한다. 저장소 루트에서 `python scripts/build-docs.py`를 실행하면 대상 글의 제목 아래에 영상 패널을 붙인다.
