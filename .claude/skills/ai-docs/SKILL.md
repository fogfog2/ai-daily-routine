# AI Docs 루틴

**절차는 저장소 루트의 `ROUTINE.md` 에 있다. 그 파일을 읽고 그대로 수행한다.**

이 스킬은 진입점 역할만 한다. 절차를 여기 중복해 적지 않는다.

## 수행

`ROUTINE.md` 의 **[B] 기술 문서 — 매일 1편** 과 **[C] 배포** 를 수행한다.

주제는 `DOCS-BACKLOG.md` 에서 고른다. 가장 좋은 후보는
**기존 문서가 여러 번 언급했는데 전용 문서가 없는 것**이고, **vision 분야를 우선**한다.

## 실행 위치

이 저장소의 루트에서 작업한다. 집 PC 와 클라우드(Claude Code routines) 양쪽에서 돈다.
경로를 가정하지 않는다.

**클라우드에서 처음 돌 때는 `site-pages/` 가 없다.** 공개 사이트는 별도 저장소라
`ship-docs.sh` 가 자동으로 clone 한다. 수동으로 만들 필요 없다.

## 반드시 지킬 것

- 문서 **HTML 을 직접 편집하지 않는다.** `scripts/docs/gen_<주제>.py` 를 고친다.
- **수치는 직접 계산하거나 1차 출처로 확인**한다. 기억으로 쓰지 않는다.
- 배포는 `./scripts/ship-docs.sh` 로만. 검증 5단계를 건너뛰지 않는다.
- **공개 사이트(ai-concepts)는 `main` 에 직접 푸시한다.** Pages 가 `main` 을 서빙하므로
  세션 작업 브랜치에 올리면 사이트에 반영되지 않는다. `ship-docs.sh` 를 끝까지 돌리면 된다.
  루틴 저장소(ai-daily-routine)는 반대로 지정 브랜치를 쓴다. 자세한 것은 `ROUTINE.md` [C].
- **기존 문서와 겹치면 새로 쓰지 않는다.** 그 문서의 생성기에 절을 추가한다.
- **양방향 링크.** 새 문서에서 기존으로, 기존 문서에서 새 문서로 둘 다 건다.
- 후보가 정말 떨어졌으면 대충 쓰지 말고 사용자에게 알린다.
