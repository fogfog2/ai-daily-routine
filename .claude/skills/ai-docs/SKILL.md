# AI Docs 루틴

**절차는 저장소 루트의 `ROUTINE.md` 에 있다. 그 파일을 읽고 그대로 수행한다.**

이 스킬은 진입점 역할만 한다. 절차를 여기 중복해 적지 않는다.

## 수행

- **판정만 필요하면** → `ROUTINE.md` 의 **[B] 문서 영향 판정**
- **실제 작성·배포까지면** → `ROUTINE.md` 의 **[C] 문서 반영**

인자가 없으면 `DOCS-BACKLOG.md` 대기열 상태를 보고 판단한다.
오늘 이미 판정했으면 [C] 로 간다.

## 실행 위치

이 저장소의 루트에서 작업한다. 집 PC 와 클라우드(Claude Code routines) 양쪽에서 돈다.
경로를 가정하지 않는다.

**클라우드에서 처음 돌 때는 `site-pages/` 가 없다.** 공개 사이트는 별도 저장소라
`ship-docs.sh` 가 자동으로 clone 한다. 수동으로 만들 필요 없다.

## 반드시 지킬 것

- 문서 **HTML 을 직접 편집하지 않는다.** `scripts/docs/gen_<주제>.py` 를 고친다.
- **수치는 직접 계산하거나 1차 출처로 확인**한다. 기억으로 쓰지 않는다.
- 배포는 `./scripts/ship-docs.sh` 로만. 검증 5단계를 건너뛰지 않는다.
- 대기열이 비면 **아무것도 하지 않는다.** 억지로 주제를 만들지 않는다.
