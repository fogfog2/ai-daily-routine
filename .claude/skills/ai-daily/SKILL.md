# AI Daily 루틴

**절차는 저장소 루트의 `ROUTINE.md` 에 있다. 그 파일을 읽고 그대로 수행한다.**

이 스킬은 진입점 역할만 한다. 절차를 여기 중복해 적지 않는다 —
사용자가 `ROUTINE.md` 만 고쳐서 루틴을 바꿀 수 있어야 하기 때문이다.

## 수행

1. `ROUTINE.md` 를 읽는다.
2. **[A] 데일리 뉴스 → [B] 기술 문서 1편 → [C] 배포** 를 순서대로 수행한다.
   두 작업은 서로 독립이다. 뉴스가 부실해도 문서는 그대로 쓴다.
3. `ROUTINE.md` 의 "보고" 항목대로 사용자에게 보고한다.

## 반드시 지킬 것

`ROUTINE.md` 의 원칙과 동일하다. 충돌하면 `ROUTINE.md` 가 우선한다.

- **뉴스는 오늘 것만 쓴다.** 검색 전에 전날 `archive/` 를 읽고,
  이미 실린 사건은 다시 쓰지 않는다. 건수를 채우려고 끌어오지 않는다.
- **AI 전 분야를 본다.** 에이전트·코딩 도구에 쏠리지 않게 한다 —
  비전·음성·과학·로보틱스·시스템까지 본다. `산업`(인사·투자) 은 회차당 2건 이하.
- **문서는 매일 1편 쓴다.** 기존 문서가 언급했지만 설명이 부족한 것을 골라 쓴다.
- **기존 문서와 겹치면 새로 쓰지 않는다.** 그 문서를 늘린다.
- **양방향으로 링크한다.** 새 문서만 링크를 걸고 끝내지 않는다.
- **수치는 기억으로 쓰지 않는다.** 계산하거나 1차 출처로 확인한다.
- **검증을 통과하지 못하면 배포하지 않는다.** `ship-docs.sh` 가 알아서 멈춘다.
- **이 저장소는 공개다.** 로컬 경로·내부 IP·키가 들어가면 안 된다.
- 배포 대상은 **GitHub Pages 하나뿐이다.** 집 서버·로컬 서버·Tailscale 은 쓰지 않는다.
