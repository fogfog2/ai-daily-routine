# AI Daily 루틴

**절차는 저장소 루트의 `ROUTINE.md` 에 있다. 그 파일을 읽고 그대로 수행한다.**

이 스킬은 진입점 역할만 한다. 절차를 여기 중복해 적지 않는다 —
사용자가 `ROUTINE.md` 만 고쳐서 루틴을 바꿀 수 있어야 하기 때문이다.

## 수행

1. `ROUTINE.md` 를 읽는다.
2. "오늘 무엇을 할지 정하기" 표에 따라 오늘 할 작업을 정한다.
3. 해당 절([A] 뉴스 수집 / [B] 문서 영향 판정 / [C] 문서 반영)을 순서대로 수행한다.
4. `ROUTINE.md` 의 "보고" 항목대로 사용자에게 보고한다.

## 반드시 지킬 것

`ROUTINE.md` 의 원칙과 동일하다. 충돌하면 `ROUTINE.md` 가 우선한다.

- **매일 문서를 쓰지 않는다.** 판정 결과 해당 없으면 아무것도 하지 않고 그렇게 보고한다.
- **수치는 기억으로 쓰지 않는다.** 계산하거나 1차 출처로 확인한다.
- **검증을 통과하지 못하면 배포하지 않는다.** `ship-docs.sh` 가 알아서 멈춘다.
- **이 저장소는 공개다.** 로컬 경로·내부 IP·키가 들어가면 안 된다.
- 배포 대상은 **GitHub Pages 하나뿐이다.** 집 서버·로컬 서버·Tailscale 은 쓰지 않는다.
